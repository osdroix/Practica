¿Qué estás practicando con este reto?

Con este ejercicio estás repasando varios conceptos básicos de JavaScript:

  • Funciones: un bloque de código reutilizable que recibe valores (parámetros) y devuelve un resultado.
  • Parámetro valor: es el dato que le pasas a la función para que construya el mensaje.
  • Valor de retorno: la función usa return para devolver el string final al lugar desde donde fue llamada.
  • Tipos primitivos: number, string, boolean, undefined y también object para objetos.
  • typeof: operador que devuelve el tipo del valor (por ejemplo, typeof 10 da "number").
  • Concatenación de strings: el operador + sirve para unir textos y valores y formar un solo mensaje.
